# Coursework

Practice and assessment, separate from the chapters. The chapters teach; this is where you prove to yourself it stuck.

| | What it is | Covers | Solutions |
|---|---|---|---|
| **[Practice workbook](sessions_0_to_7/)** | 127 exercises across eight sets, from warm-ups to challenges, plus two final projects | Sessions 0–7 | Worked solutions for every exercise, plus runnable code |
| **[Sessions 4–6 assessment](module_1_sessions_4_to_6.md)** | A shorter, test-style check: knowledge questions, one coding challenge, one bug to find | Sessions 4–6 | [Answer key](module_1_sessions_4_to_6.md) (at the bottom) and [solution code](module_1_sessions_4_to_6_solution.dart) |

**Start with the workbook.** Do each set straight after reading its chapter. Take the assessment afterwards, as a check that it's all still there.

As with everything in this repository: **do the work in your own folder, never in here.** The [workbook guide](sessions_0_to_7/README.md#setting-up-sessions-4-to-7) shows you how to set that up.
