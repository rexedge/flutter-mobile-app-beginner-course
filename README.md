# Flutter for Beginners

**12 weeks · 36 sessions · zero coding experience required.**

This is the student handbook for the Flutter Mobile App Development (Beginner) course. Every session has a written read-through you can work through on your own, plus the code that goes with it.

You end this course having built eight working mini-apps and one real, installable app called **TaskFlow**.

**New here?** Read [START-HERE.md](START-HERE.md) first — three minutes, and it saves a lot of frustration later. Then [Session 0](sessions/00-intro-to-git-and-github/) gets the files onto your computer.

## Course baseline

Everything here is written for **Flutter 3.44.x stable** and **Dart 3.12**, with Material 3 and null safety on. If a tutorial you find elsewhere looks different from what you see here, check its date — Flutter moves fast.
