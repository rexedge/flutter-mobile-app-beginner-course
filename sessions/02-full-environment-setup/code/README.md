# Session 2 — Code

There is no `starter/` folder this session. Your starting point is an empty folder — you generate the project yourself, live, with:

```
flutter create first_app
```

That's the exercise.

`final/first_app/` is the exact result you should end up with: Flutter's own stock counter-app template, generated by `flutter create` under Flutter 3.44.x and left completely unmodified.

Use it to compare against yours if something looks off. You don't need to copy anything out of it.
