# Session 3 — Code

This is the first session where `starter/` and `final/` genuinely differ.

- **`starter/first_app/`** — the project carried over unchanged from Session 2. If you still have your own `first_app` from Session 2, use that instead; this copy is here in case you need a clean one.
- **`final/first_app/`** — the same project after the session's four hot-reload edits: the `MaterialApp` title, the seed colour, the home screen's title text, and the floating action button's icon.

Edit 3 is meant to be personalized, so your version will read differently from this one. That's correct.

## Running either version

```
cd starter/first_app     # or final/first_app
flutter pub get
flutter run
```
